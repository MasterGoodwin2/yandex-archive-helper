# ЯндексАрхив Helper (ЯндексАрхив помощник)

Кроссбраузерное расширение (Manifest V3) для **Google Chrome / Яндекс.Браузера / Microsoft Edge** и **Mozilla Firefox** для работы с распознанным текстом на портале **Яндекс.Архив** (`ya.ru/archive/*`, `yandex.ru/archive/*`).

## Что нового в версии 1.4.0
- Исправлена загрузка словаря имён `NamesRu` в Firefox (запись в `globalThis.NamesRu` и `window.NamesRu`), устраняющая пустую базу имён.
- Убрана автозамена `Иван` → `Иоанн` из словаря по умолчанию (имя `Иван` сохраняется как `Иван`).
- Генерализация крестьянских имён и отчеств XIX века без дворянских `-ич`/`-овна`.
