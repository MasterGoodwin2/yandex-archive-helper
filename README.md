# ЯндексАрхив Helper (ЯндексАрхив помощник)

Кроссбраузерное расширение (Chrome / Edge / Яндекс.Браузер и Mozilla Firefox, Manifest V3) для работы с распознанным текстом на страницах **Яндекс.Архива** (`ya.ru/archive/*`, `yandex.ru/archive/*`).

## Возможности
- **Плавающее окно поверх страницы**: перемещение за заголовок (`drag & drop`), свободное растягивание и сужение (`resize`), сворачивание.
- **Извлечение и сшивка текста**: чтение `joinedTextBlocks` и `textBlocks` из `__NEXT_DATA__` с резервным поблочным анализом DOM-верстки справа от скана.
- **Три режима обработки текста**:
  1. *Оригинал* — сшитый распознанный текст без изменений.
  2. *Замена* — нормализация старых и разговорных форм имён по настраиваемому справочнику (с поддержкой дореволюционной орфографии `ѣ, і, ѳ, ъ`) и встроенной базе `names-ru.js`.
  3. *Подстановка* — замена имён + автоматическая подстановка отчеств и вычисление примерного года рождения по возрасту и дате документа.
- **Гибкая настройка оформления и быстрых кнопок** (через окно «Сведения о расширении» / «Настройки»):
  - ширина рамки плавающего окна;
  - расположение панели быстрых кнопок (снизу, справа или слева от окна);
  - выбор активных кнопок экспорта (копирование выделения или всего текста в буфер обмена, в новый `.txt` файл или дозапись в уже открытый `.txt` файл);
  - выбор темы (системная, светлая, тёмная), цвета отображаемого текста и цветов выделения.

## Установка

### Google Chrome / Яндекс.Браузер / Edge
1. Откройте `chrome://extensions/` и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку с файлами расширения.
3. Для настройки откройте **Сведения** → **Параметры расширения** (или нажмите `⚙` в заголовке плавающего окна).

### Mozilla Firefox
1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение...** и выберите файл `manifest.json`.
3. Для настройки откройте `about:addons` → **ЯндексАрхив Helper** → **Настройки**.
